STEP 5: MYSQL DATABASE CONFIGURATION & INITIALIZATION
================================================================================
Purpose: Set up the MySQL connection on port 3307, configure credentials in .env,
and create the 'rentido' database schema with utf8mb4 encoding.
Working Directory: C:\Users\javak\project-nithish

Commands:
# 1. Environment variables (.env file in project-nithish/):
DJANGO_SECRET_KEY=your-secret-key
DJANGO_DEBUG=True
DB_ENGINE=django.db.backends.mysql
DB_NAME=rentido
DB_USER=root
DB_PASSWORD=root123
DB_HOST=127.0.0.1
DB_PORT=3307

# 2. Create the database in MySQL:
.\.venv\Scripts\python -c "import pymysql; conn = pymysql.connect(host='127.0.0.1', port=3307, user='root', password='root123'); cur = conn.cursor(); cur.execute('CREATE DATABASE IF NOT EXISTS rentido CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;'); conn.commit(); print('Database rentido is ready!'); conn.close()"

Expected Result:
"Database rentido is ready!" printed.
